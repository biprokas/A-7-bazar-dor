# 🛒 বাজার দর | BazarDor

Bazar Dor is a daily essentials price-tracking web application for Bangladesh. Users can explore product prices, compare market information, and track price changes.

## 🛠️ Technologies Used

* Next.js (App Router)
* React
* JavaScript (JSX)
* Tailwind CSS
* HeroUI
* Better Auth
* MongoDB

## ✨ Key Features

1. **Product Listings:** Browse daily essential products and their prices.
2. **Price Tracking:** View products with increasing and decreasing prices.
3. **Category Filtering & Sorting:** Browse categories and sort products by price.
4. **Product Details:** Explore detailed product information and market-wise prices.
5. **Authentication & Profile:** Sign up, sign in, access protected pages, and update profile information.
